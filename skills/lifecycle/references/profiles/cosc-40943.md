## Course rules on top of the cycle

- The stakeholder is "the client"; client meetings follow the course's interview guide, with notes sent within 24 hours.
- Weekly activity report lines start with the use case ID; they are the time log for calibration.
- Release values are `v0.1.0`, `v0.2.0`, `v1.0.0`, `Spring`, or `Out`.
- A use case's design is approved when a teammate who did not write it merges the pull request; the TA reviews at each checkpoint.
- Personal deny rules (force-push, `gh pr merge`, `gh repo delete`) go in each student's user settings via `/permissions`, as the course's Agent Setup §9 describes.
